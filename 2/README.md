# Задание

Реализовать игру «Жизнь» («Game of Life»).
Игрок должен иметь следующие возможности:
- указать начальное состояние игрового поля;
- перейти к следующему поколению по нажатию клавиши «стрелка вправо» (новое поколение должно быть просчитано по правилам игры);
- вернуться к предыдущему поколению по нажатию клавиши «стрелка влево» (данные о предыдущих поколениях должны извлекаться из хранящейся истории поколений).
История поколений должна быть представлена с помощью логической структуры данных «стек».
Реализация стека на основе вектора предполагает удаление из него наиболее старой записи в случае возникновения переполнения.

# Функционал программы 

- 'n' - генерация следующей кадра в соответствии с правилами игры «Жизнь».
- 'p' - возвращение на шаг назад, то есть возвращение на предыдущий кадр.
- 'v' - вывод текущего кадра.
- 'q' - сохранение кадра в файл, завершение выполнения программы.

# Компиляция 

- "PROG\_TYPE" выбор реализации стека: 
    - "PROG\_TYPE=vector" - реализация стека на основе вектора и библиотеки "stack\_library\_vector.c" соответственно.
    - "PROG\_TYPE=list" - реализация стека на основе списка и библиотеки "stack\_library\_list.c" соответственно.
- "LIBRARY\_TYPE" выбор реализации библиотеки:
    - "LIBRARY\_TYPE=static" - компиляция статической библиотеки.
    - "LIBRARY\_TYPE=dynamic" - компиляция динамической библиотеки.

# Запуск

Запуск осуществляется c передачей скомпилированной программе текстового файла- начальное состояние игрового поля.
    Пример: "./game\_of\_life test\_1.txt"
*Имеется 6 файлов с генерациями игрового поля(test_1.txt, test_2.txt и тд.)
*Сохранение программы проиходит в тот же файл, откуда было взято начальное игровое поле.
